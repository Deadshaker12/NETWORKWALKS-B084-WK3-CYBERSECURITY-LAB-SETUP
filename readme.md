# WK3 - Password Cracking Lab
## Using Johnny & NetworkWalks Hash Calculator and password cracker on Windows

### 📋 Lab Overview
In this lab, I learned how to extract hash from a locked pdf and crack the password.

> **⚠️ Disclaimer:** This lab was done for educational only.

---

### 🎯 Lab Objectives
- Learn how to generate a hash from a pdf.
- Learn how to use Johnny (John the Ripper GUI) on Windows to crack password.
- Understand why weak passwords are dangerous

---

| Tool | Use |

### 🧪 Lab Steps

## Method 1
#### Step 1: Generate Hash with NetworkWalks Tool
1. Open Chrome / Edge on Windows.
2. Type **NetworkWalks Hash Calculator**.
3. Upload the locked pdf to generate hash of the pdf.

#### Step 2: Cracking password with NetworkWalks Tool
1. Type **NetworkWalks password cracker**.
2. Paste the hash i.e. the one generated by NetworkWalks Hash Calculator, in the pdf hash.
3. Click on Start Cracking, to get the password.
4. Now you can use the password to open the pdf.

## Method 2
#### Step 1: Setting up Johnny on Windows
1. Download and install **Johnny** for Windows.
2. Download **John the ripper** for Windows.
3. Go to Settings and link `john.exe` to johnny.

#### Step 2: Extracting hash from the locked pdf
1. Open Chrome / Edge on Windows.
2. Type **Onlinehashcrack**.
3. Upload the locked pdf to generate hash of the pdf, and copy the hash.
3. Open **Notepad** on Windows
4. Paste the hash inside Notepad
5. Save it on Desktop as `hash.txt`

#### Step 3: Start Cracking
1. Open password file.
2. Click **Start Attack**
3. Wait for Johnny to try passwords from its wordlist
4. If the password is weak, it will appear in the **Password** column
5. Use the password you get, to open the locked pdf.

### 💡 What I Learned
1. **Weak passwords fail fast:** `12345` and `password123` are in every wordlist. They crack in seconds.
2. **Length matters:** Longer passwords take much more time to crack.
3. **Hash is not encryption:** Hashing hides the password, but does not make a weak password safe.
4. **Wordlist attack works:** Attackers don't guess one by one. They use a list of millions of common passwords like `rockyou.txt`.
5. **Strong passwords win:** A password with uppercase, lowercase, numbers, and symbols cannot be cracked easy.

---

### 🛡️ How To Protect Yourself
- Use at least **12-14 characters**
- Mix **A-Z, a-z, 0-9, !@#$**
- Don't use your name, birthday, or `12345`
- Don't reuse the same password on all sites
- Use a **Password Manager** like Bitwarden
- Turn on **2FA / MFA** everywhere
